# 开发问题集

## 一、已确认决策

### 1. JSON 结构方案

**选项 C：混合方案（已确认）**

```go
type ExtractResult struct {
    Interactions         []Interaction       `json:"interactions"`
    PageMetadata         PageMetadata        `json:"page_metadata,omitempty"`
```

### 2. 矩阵题行列提取的 HTML 结构依赖

| 风险 | 说明 |
|---|---|
| 不同问卷平台 HTML 结构差异大 | Alchemer/Qualtrics/SurveyGizmo 的矩阵 DOM 各不相同 |
| "转置矩阵"判断依赖 class 属性 | 需要正确定位 `class="QuestionBody Transposed q-matrix"` |
| Rows[i].Options 赋值时机 | 矩阵行数未知时如何预分配？ |

**回**: 为每个问卷平台写独立的 HTML 解析器

### 3. 人设上下文

**问题**: 提取题目列表是否需要人设上下文？目前 prompts.yaml 的 analyze 顺序中没有 persona 块。

**答**: 这个放在下一步才考虑，我们现在一步步的开发。只做 YAML 的优化。

### 4. 性能与成本考量

**问题**: 是否需要增量提取（只处理新页面）？现有 `storage/cache/` 目录已有缓存。

**答**: 只处理新页面，缓存做它用。因为每次打开调查的 URL，只有 page_id 是相同的，并且选项有可能是随机变动的。

### 5. 测试数据来源

**答**: 在 cmd cli 环境，由用户拖入 html 源码数据。不走缓存的路径。在 cache 如果 page_id 同名可以覆盖。

### 6. 输出数据的后续使用

- **6-1**: 结构体是否需要携带更多字段（如 xpath）？
  **回**: 不需要，只在 `@configs/page-fingerprints.yaml:77-81` 带上指定的 `next_button` 用于判断命中翻页使用。

- **6-2**: 矩阵题需要 Rows/Cols 元数据，存放在 QuestionResult 内还是独立返回？
  **回**: 存放在 QuestionResult 内。

- **6-3**: `page_summary` 用途，是答题的一句话极简的总结。需要在 QuestionResult 中保留。

- **6-4**: QuestionResult 新增一个字段对应 `has_next_button: true/false`，表示这个页面是否有下一页的按钮。

### 7. 错误处理

1. **AI 调用失败**（网络/超时）重试 3 次，间隔限定为 1s，仍失败则返回空列表 + error
2. **JSON 解析失败** - 记录原始响应到 `logs/extract_failures/`，返回 error
3. **HTML 结构异常** - 记录原始响应到 `logs/extract_failures/`，返回 error

### 8. 模块拆分决策

当前观察：`core/` 下只有 `cleaner/`、`storage/`、`logger/` 三个子目录，建议新建 `core/extractor/`。

### 9. 空页面 / 仅导航按钮页面

1. **感谢页**（`thank_you_page: true`）- 直接返回空 interactions，跳过 AI 调用
   **回**: 返回 `interactions{subject, showAnswer}`
   - `subject`: {{subject}}
   - `showAnswer`: `"[无题目页面]" + 将标题翻译为中文用极简的说明一下`
   - 两个字段，无需其他字段

2. **只有 "Next" 按钮的页面** - 回复同上

3. **只有一道题且选项被隐藏** - 需要额外处理：等待选项加载？回复同上

### 10. 嵌套矩阵 / 分组矩阵

1. 同一页面有多个独立矩阵，需要分组，每个矩阵单独生成 interactions
   **回**: 不单独生成 interactions，所有的答案合并在 interactions

2. 矩阵内嵌套子分组，prompts.yaml 提到 mixed 类型作为兜底
   **回**: 分块 `mixed_block`

## 二、数据结构终稿

### ExtractResult（根结构）

```go
type ExtractResult struct {
    Interactions         []Interaction       `json:"interactions"`
    PageMetadata         PageMetadata        `json:"page_metadata,omitempty"`
    OriginalQuestionType []OriginalQuestion `json:"original_question_type,omitempty"`
    PageSummary          string              `json:"page_summary,omitempty"`
}
```

### Interaction（单条题目）

```go
type Interaction struct {
    Subject      string `json:"subject"`        // 题目文本
    ShowAnswer   any    `json:"showAnswer"`     // string 或 []string
    QuestionType string `json:"question_type"`  // AI 返回 26 种题型之一
}
```

**关键点**：
- `QuestionType` 由 AI 返回，严格按 26 种题型选择
- 矩阵题的 `ShowAnswer` 格式：`{row1} -> {col1}\n{row2} -> {col2}\n...`

### PageMetadata（页面元数据）

```go
type PageMetadata struct {
    PageID        string `json:"page_id"`         // 本地生成，不是 AI 返回
    HasNextButton bool   `json:"has_next_button"` // AI 返回
}
```

**关键点**：
- `page_id` 是本地的，**严禁使用 AI 返回的 page_id**
- `has_next_button` 由 AI 返回
- 删除了：`question_type`、`has_submit_button`、`is_thank_you_page`、`is_matrix_page`

### OriginalQuestion（原始题目信息）

```go
type OriginalQuestion struct {
    Subject       string             `json:"subject"`
    QuestionType  string             `json:"question_type"`
    // 简单题用 Options
    Options       []string           `json:"options,omitempty"`
    // 矩阵题用 MatrixOptions（按行分组）
    MatrixOptions []MatrixRowOptions `json:"matrix_options,omitempty"`
}

type MatrixRowOptions struct {
    RowLabel string   `json:"row_label"` // 行标签
    Cols     []string `json:"cols"`      // 该行的列选项
}
```

**关键点**：
- **简单题**：`Options` 是普通数组
  ```json
  ["Very Satisfied", "Satisfied", "Neutral", "Dissatisfied", "Very Dissatisfied"]
  ```
- **矩阵题**：`MatrixOptions` 按行分组
  ```json
  [
    {"row_label": "row1", "cols": ["col1_1", "col1_2", "col1_3"]},
    {"row_label": "row2", "cols": ["col2_1", "col2_2", "col2_3"]},
    {"row_label": "row3", "cols": ["col3_1", "col3_2", "col3_3"]}
  ]
  ```

### 矩阵题 ShowAnswer 格式

矩阵题的 `ShowAnswer` 是**字符串**，格式为：

```
{row1} -> {col1}
{row2} -> {col2}
{row3} -> {col3}
...
```

## 三、26 种题型（AI 返回参考）

> `QuestionType` 字段由 AI 从以下 26 种题型中选择：

1. single（单选）
2. multiple（多选）
3. matrix_radio（矩阵单选）
4. matrix_checkbox（矩阵多选）
5. matrix_dropdown（矩阵下拉）
6. matrix_text（矩阵文本输入）
7. matrix_rating（矩阵评分）
8. matrix_ranking（矩阵排序）
9. dropdown（下拉单选）
10. dropdown_multiple（下拉多选）
11. text_short（短文本输入）
12. text_long（长文本输入）
13. number（数字输入）
14. date（日期选择）
15. time（时间选择）
16. datetime（日期时间选择）
17. slider（滑块）
18. ranking（排序题）
19. semantic_differential（语义差异题）
20. constant_sum（总和题）
21. file_upload（文件上传）
22. captcha（验证码）
23. likert_scale（李克特量表）
24. Net_Promoter_Score（NPS）
25. matrix_mixed（矩阵混合）
26. mixed_block（混合块）
