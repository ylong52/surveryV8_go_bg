# 题型库大全 v1.0

> 统一标准问卷题型库，涵盖 26 种题型，支持快速 HTML 结构识别和答案提取

---

## 一、基础选择类（Choice Questions）

### 1. 单选题 (single)

| 属性 | 说明 |
|-----|------|
| **标识符** | `single` |
| **HTML特征** | `<input type="radio">` + `<label>` 组合 |
| **选项数量** | 2-N 个，互斥 |
| **答案格式** | 单个选项值（字符串） |
| **action_type** | `CLICK` |
| **识别要点** | 检查所有 input 的 name 属性相同，type="radio" |

**示例**：
```
你目前的居住国家是？
○ 美国 ○ 中国 ○ 日本 ○ 英国
```

---

### 2. 多选题 (multi)

| 属性 | 说明 |
|-----|------|
| **标识符** | `multi` |
| **HTML特征** | `<input type="checkbox">` + `<label>` 组合 |
| **选项数量** | 2-N 个，可多选 |
| **答案格式** | 数组 `["选项1", "选项2"]` |
| **action_type** | `CLICK` |
| **识别要点** | checkbox 可多选，name 属性带 `[]` 或各不相同 |

**示例**：
```
你喜欢哪些运动？（可多选）
☐ 篮球 ☐ 足球 ☐ 游泳 ☐ 跑步
```

---

### 3. 排他多选题 (exclusive_multi)

| 属性 | 说明 |
|-----|------|
| **标识符** | `exclusive_multi` |
| **HTML特征** | checkbox + 包含 "None of these" / "以上都不是" 等排他选项 |
| **选项数量** | N 个，选排他项则清除其他选择 |
| **答案格式** | 数组（含排他选项时只有排他项） |
| **action_type** | `CLICK` |
| **识别要点** | 存在 "None / No / 以上都不是 / 都不" 等文字的选项 |

**示例**：
```
你使用过哪些社交媒体？（可多选）
☐ 微信 ☐ 微博 ☐ 抖音
☐ 以上都没有
```

---

### 4. 下拉选择题 (dropdown)

| 属性 | 说明 |
|-----|------|
| **标识符** | `dropdown` |
| **HTML特征** | `<select>` + `<option>` 组合 |
| **选项数量** | 2-N 个，只能单选 |
| **答案格式** | 单个 option 值或显示文本 |
| **action_type** | `CLICK`（选择下拉项） |
| **识别要点** | select 标签，常见于国家/地区/年份选择 |

**示例**：
```
你的国籍：
[请选择 ▼]
```

---

## 二、填空输入类（Input Questions）

### 5. 短文本填空 (short_text)

| 属性 | 说明 |
|-----|------|
| **标识符** | `short_text` |
| **HTML特征** | `<input type="text">` 或 `<input type="email/tel/url">` |
| **内容限制** | 单行，字数限制（通常 100 字以内） |
| **答案格式** | 字符串 |
| **action_type** | `INPUT_BLUR` |
| **识别要点** | input[type=text]，无 maxlength 或 maxlength < 200 |

**示例**：
```
请输入您的邮编：_______________
```

---

### 6. 长文本填空 (long_text)

| 属性 | 说明 |
|-----|------|
| **标识符** | `long_text` |
| **HTML特征** | `<textarea>` 标签 |
| **内容限制** | 多行，可输入较长内容 |
| **答案格式** | 字符串（支持换行） |
| **action_type** | `INPUT_BLUR` |
| **识别要点** | textarea 标签，可 resize |

**示例**：
```
请描述您对产品的使用体验：

[                                          ]
[                                          ]
```

---

### 7. 数字输入 (numeric)

| 属性 | 说明 |
|-----|------|
| **标识符** | `numeric` |
| **HTML特征** | `<input type="number">` 或 `<input>` + step/min/max 属性 |
| **内容限制** | 纯数字，可设置范围 |
| **答案格式** | 数字或字符串数字 |
| **action_type** | `INPUT_BLUR` |
| **识别要点** | input[type=number]，或带有 step 属性 |

**示例**：
```
您家里有几口人？
[  3  ]
```

---

### 8. 日期/时间输入 (datetime)

| 属性 | 说明 |
|-----|------|
| **标识符** | `datetime` |
| **HTML特征** | `<input type="date/time/datetime-local">` 或 datepicker 组件 |
| **内容限制** | 日期或时间值 |
| **答案格式** | ISO 日期字符串 |
| **action_type** | `INPUT_BLUR` / `CLICK` |
| **识别要点** | input[type=date] 等，或 class 含 "datepicker/calendar" |

**示例**：
```
您的出生日期：
[ 2024-01-15  ]
```

## 三、量表评分类（Scale Questions）

### 9. 李克特量表 (likert)

| 属性 | 说明 |
|-----|------|
| **标识符** | `likert` |
| **HTML特征** | 多行，每行一个 statement + N 个 radio 选项 |
| **选项结构** | 如：同意程度 1-5 / 满意程度 1-10 |
| **答案格式** | 数组 `[{row: "陈述1", value: "同意"}, ...]` |
| **action_type** | `CLICK` |
| **识别要点** | 多行 radio，每行 subject 不同，选项相同 |

**示例**：
```
请评价以下陈述：

                    非常同意  同意  中立  不同意  非常不同意
产品质量很好          ○        ○     ○      ○        ○
服务态度很好          ○        ○     ○      ○        ○
价格合理              ○        ○     ○      ○        ○
```

---

### 10. 水平量表 (horizontal_scale)

| 属性 | 说明 |
|-----|------|
| **标识符** | `horizontal_scale` |
| **HTML特征** | LabelContainer 结构，水平排列选项 |
| **选项结构** | 标签 + 分值（如 😠 😕 😐 🙂 😍 → 1-5） |
| **答案格式** | 单个数值或标签 |
| **action_type** | `CLICK` |
| **识别要点** | 选项水平排列，带数值，class 含 "horizontal/scale" |

**示例**：
```
您对本次服务满意吗？
😠        😕        😐        🙂        😍
1分       2分       3分       4分       5分
```

---

### 11. 滑块评分 (slider)

| 属性 | 说明 |
|-----|------|
| **标识符** | `slider` |
| **HTML特征** | `<input type="range">` 或 自定义滑块组件 |
| **选项结构** | 数值范围，拖动选择 |
| **答案格式** | 数值 |
| **action_type** | `CLICK` / `INPUT_BLUR` |
| **识别要点** | input[type=range]，或 class 含 "slider/range" |

**示例**：
```
请调整您的满意度：0 ──●─────────── 100
当前值：75
```

---

### 12. 星标评分 (rating_stars)

| 属性 | 说明 |
|-----|------|
| **标识符** | `rating_stars` |
| **HTML特征** | ⭐⭐⭐⭐⭐ 星级图标，可点击 |
| **选项结构** | 1-5 星或 1-10 星 |
| **答案格式** | 数值 |
| **action_type** | `CLICK` |
| **识别要点** | class 含 "star/rating"，aria-label 含 "star" |

**示例**：
```
为我们的服务评分：
⭐ ⭐ ⭐ ⭐ ☆
1    2    3    4    5
```

## 四、矩阵类（Matrix Questions）

### 13. 矩阵单选题 (matrix_single)

| 属性 | 说明 |
|-----|------|
| **标识符** | `matrix_single` |
| **display_type** | `radio` |
| **HTML特征** | `<table>` + radio，行列交叉选择 |
| **选项结构** | 行为 statements/items，列为选项 |
| **答案格式** | 数组 `[{row: "行1", col: "选项1"}, ...]` |
| **action_type** | `CLICK` |
| **识别要点** | table 结构，每行 radio name 不同但相关 |

**示例**：
```
观看频率：
                    每天   每周   每月   从不
电视                  ○      ○      ○      ○
电影                  ○      ○      ○      ○
网络视频             ○      ○      ○      ○
```

---

### 14. 矩阵多选题 (matrix_multiple)

| 属性 | 说明 |
|-----|------|
| **标识符** | `matrix_multiple` |
| **display_type** | `checkbox` |
| **HTML特征** | `<table>` + checkbox |
| **选项结构** | 行为 items，列为选项类别 |
| **答案格式** | 数组 `[{row: "行1", cols: ["选项1", "选项3"]}, ...]` |
| **action_type** | `CLICK` |
| **识别要点** | table + checkbox，多选可勾 |

**示例**：
```
请勾选您家庭成员年龄段（可多选）：
                 0-6岁  7-17岁  18-34岁  35岁以上
孩子1             ☐      ☐       ☐        ☐
孩子2             ☐      ☐       ☐        ☐
```

---

### 15. 矩阵填空 (matrix_input)

| 属性 | 说明 |
|-----|------|
| **标识符** | `matrix_input` |
| **HTML特征** | `<table>` + input/textarea |
| **选项结构** | 每行有文本输入框 |
| **答案格式** | 数组 `[{row: "行1", value: "输入内容"}, ...]` |
| **action_type** | `INPUT_BLUR` |
| **识别要点** | table 内含 input/textarea |

**示例**：
```
请填写家庭成员信息：
姓名          年龄      职业
[____]       [__]      [________]
[____]       [__]      [________]
```

---

### 16. 矩阵量表 (matrix_likert)

| 属性 | 说明 |
|-----|------|
| **标识符** | `matrix_likert` |
| **HTML特征** | `<table>` + 每行多个 radio（量表选项） |
| **选项结构** | 类似 likert 但在表格中，支持复杂布局 |
| **答案格式** | 数组 |
| **action_type** | `CLICK` |
| **识别要点** | table 结构 + 多个相同值选项（同意/不同意） |

## 六、特殊题型（Special Questions）

### 19. 卡片分类/排序 (cardsort)

| 属性 | 说明 |
|-----|------|
| **标识符** | `cardsort` |
| **HTML特征** | 卡片元素 + 拖拽区域/drop zone |
| **选项结构** | 多个可拖拽卡片，分组放置 |
| **答案格式** | 对象 `{group1: ["卡片1", "卡片3"], group2: ["卡片2"]}` |
| **action_type** | `CLICK`（点击放置）/ `DRAG` |
| **识别要点** | class 含 "card/drag/drop"，draggable 属性 |

**示例**：
```
请将以下卡片拖放到合适的分类中：

[性格外向] [喜欢户外] [宅在家中] [热爱运动]

┌─────────┐    ┌─────────┐
│ 社交型  │    │ 安静型  │
│         │    │         │
└─────────┘    └─────────┘
```

---

### 20. 拖拽排序 (ranking)

| 属性 | 说明 |
|-----|------|
| **标识符** | `ranking` |
| **HTML特征** | 可排序列表 + drag handle |
| **选项结构** | 需排序的项目列表 |
| **答案格式** | 数组 `["第1名", "第2名", "第3名"]` |
| **action_type** | `CLICK`（上移下移）/ `DRAG` |
| **识别要点** | class 含 "sortable/ranking"，有排序图标 |

**示例**：
```
请按重要性排序以下因素（1=最重要）：

☰ 产品质量   [上移][下移]  排名 1
☰ 价格       [上移][下移]  排名 2
☰ 品牌       [上移][下移]  排名 3
☰ 售后服务   [上移][下移]  排名 4
```

---

### 21. 对比题 (side_by_side)

| 属性 | 说明 |
|-----|------|
| **标识符** | `side_by_side` |
| **HTML特征** | 左右分栏布局，两组选项对比 |
| **选项结构** | 两列相同或不同选项 |
| **答案格式** | 对象 `{left: "选项A", right: "选项B"}` |
| **action_type** | `CLICK` |
| **识别要点** | div 左右分栏 class 含 "left/right/side" |

**示例**：
```
请对比两个产品：

产品A                        产品B
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
☐ 功能丰富                  ☐ 功能丰富
☐ 界面美观                  ☐ 界面美观
☐ 性价比高                  ☐ 性价比高
```

---

### 22. 选项+说明填空 (choice_with_text)

| 属性 | 说明 |
|-----|------|
| **标识符** | `choice_with_text` |
| **HTML特征** | radio/checkbox + 联动 input/textarea |
| **选项结构** | 选择某项后显示文本输入框 |
| **答案格式** | 对象 `{choice: "选项", text: "补充说明"}` |
| **action_type** | `CLICK` + `INPUT_BLUR` |
| **识别要点** | 选择项后有条件显示的 input |

**示例**：
```
您的职业是？
○ 学生 → 请补充学校名称：[_______________]
○ 上班族 → 请补充职位：[_______________]
○ 其他 → 请说明：[_______________]
```

## 七、导航/说明类（Navigation）

### 23. 说明/引导页 (instruction)

| 属性 | 说明 |
|-----|------|
| **标识符** | `instruction` |
| **HTML特征** | 仅文字内容 + 导航按钮，无交互元素 |
| **选项结构** | 无选项，仅展示 |
| **答案格式** | 空数组 |
| **action_type** | `CLICK`（导航按钮） |
| **识别要点** | 无 input/select/button[交互]，有 submit/next 按钮 |

**示例**：
```
感谢您参与本次问卷调查！

接下来我们将询问您关于产品使用体验的问题。
请根据您的真实感受作答。

                    [下一页 →]
```

---

### 24. 感谢页 (thank_you)

| 属性 | 说明 |
|-----|------|
| **标识符** | `thank_you` |
| **HTML特征** | 完成提示，无导航按钮 |
| **选项结构** | 无 |
| **答案格式** | 空 |
| **action_type** | - |
| **识别要点** | text 含 "thank/完成/感谢"，无下一步按钮 |

**示例**：
```
问卷已完成！

感谢您的参与。
您的回答已成功提交。

           [关闭窗口]
```
