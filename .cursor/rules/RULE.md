# Cursor 规则

- 禁止编造内容，包括事实、数据、ID、时间等信息，若未明示均不得虚构。
- 禁止推测未明确说明的因果、动机、背景信息。
- 输出需严格遵循指令规定的格式、长度、语气，不允许自由发挥超出范围。
- 禁止以讲解、教学、劝导语气回复，避免使用“请理解”“请思考”等表达。
- 指令要求必须明确执行，不得留下“适当总结”“酌情处理”等模糊口径。
- 不得假定模型有常识，所有关键约束均需在指令中明文规定。
- 禁止在代码业务逻辑中使用兜底处理，所有分支和异常情况必须显式判断和处理，确保逻辑清晰、可预期。

- 未经明确指示的业务逻辑，禁止自行处理，必须先确认或征询意见后再执行
